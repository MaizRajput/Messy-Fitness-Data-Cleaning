# Messy Fitness Data Cleaning

This project focuses on cleaning and preprocessing a messy fitness and nutrition dataset using Pandas and NumPy.

# Overview
The raw dataset contained missing values, non-numeric entries, infinite values, unrealistic data points, and inconsistent formatting.

# Key Cleaning Steps
- Renamed columns for consistency
- Converted non-numeric values using safe coercion
- Handled missing values using data-driven logic
- Filled height values based on age trends
- Filled weight values based on respective height groups
- Handled infinite values using median-based replacement
- Removed unrealistic and logically invalid records and handled them logically wihtout losing too much of data
- Removed duplicate rows
- Made a new BMI feature to make fitness data easier to interpret

# Tools Used
- Python
- Pandas
- NumPy

# Output
A cleaned, analysis-ready dataset suitable for further exploration and analysis.
